# Vocabulary

| Word | Meaning |
|---|---|
| mailbox | stable local recipient |
| thread | remote conversation bound to one mailbox |
| letter | immutable posted or replied content |
| receipt | immutable acceptance of a posted letter into a thread |
| pending | veiled reply awaiting its thread |
| request | idempotency key for a posted letter |
| cause | idempotency and causal key for a replied letter |
